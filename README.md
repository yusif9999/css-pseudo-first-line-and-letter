# Web Developers Summit 2026 - Landing Page

A structured, responsive landing and registration page built for a fictional Web Developers Summit. This project was developed to strictly practice and demonstrate core HTML semantics and specific CSS concepts, without relying on modern layout modules like Flexbox or Grid.

## 🎯 Project Focus & CSS Highlights

This project heavily focuses on classic CSS layout techniques and advanced text/form formatting. Key CSS concepts implemented include:

*   **Advanced Typography:** Utilizing `::first-letter` (drop cap effect) and `::first-line` pseudo-elements to create magazine-style text layouts.
*   **Pseudo-Classes:** Extensive use of pseudo-classes for form validation and state management (`:invalid`, `:disabled`, `:checked`), as well as link states (`:link`, `:visited`, `:focus`, `:hover`, `:active`).
*   **Combinators:** Using adjacent sibling combinators (`+`) to style labels dynamically when a checkbox is `:checked`.
*   **Classic Layouts:** Managing page structure using `float` properties alongside `clear: both` (clearfix logic) for the responsive table area.
*   **Positioning:** Implementing `position: sticky` for the navigation bar and `position: absolute` / `relative` for banner badges.

## 🚀 Features

*   **Fixed Navigation:** A sticky header that follows the user as they scroll.
*   **Interactive Form:** A registration form with visual feedback for invalid email inputs and disabled state styling for inactive discount codes.
*   **Custom Checkbox Styling:** Pure CSS dynamic styling for the agreement checkbox.
*   **Styled Data Table:** A clean, easy-to-read event schedule table with hover effects on rows.

## 🛠️ Technologies Used

*   **HTML5:** Semantic structuring.
*   **CSS3:** Styling, positioning, and pseudo-element manipulation.
*   **Google Fonts:** Custom typography (Roboto).
*   **FontAwesome:** Vector icons for visual enhancement.
